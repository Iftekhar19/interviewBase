## 📌 Overview
**InterviewBase** is a modern, AI-driven platform to help users prepare for interviews, track progress, and improve performance with real-time insights.

Whether you're a student, a job seeker, or an HR professional, InterviewBase makes interview preparation **interactive, personalized, and data-driven**.

---

## ✨ Features
- 🎯 **AI-Powered Questions** – Generate interview questions based on job role & difficulty.
- 📊 **Performance Analytics** – Track progress & identify improvement areas.
- 📝 **Custom Mock Interviews** – Simulate real-world interview scenarios.
- 🔐 **Secure Authentication** – Firebase/NextAuth-based login.
- 🎨 **Beautiful UI** – Built with TailwindCSS + shadcn/ui components.
- 📱 **Responsive Design** – Works seamlessly on desktop & mobile.

---

## 🛠️ Tech Stack
**Frontend**
- [Next.js](https://nextjs.org/) – App Router
- [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- [Framer Motion](https://www.framer.com/motion/) – Animations

**Backend**
- [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/) (if applicable)
- [MongoDB](https://www.mongodb.com/) – Database
- [Firebase Auth](https://firebase.google.com/docs/auth) / NextAuth – Authentication

**Other Tools**
- [Lucide Icons](https://lucide.dev/)
- [Axios](https://axios-http.com/)
- [Vercel](https://vercel.com/) – Deployment
